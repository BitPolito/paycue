Bounty board

Merge a pull request that closes a bounty issue and its author is paid automatically, powered by Payhook.

Claim a bounty in four steps

  1. Register your payout addressYour GitHub username and a Liquid address (L-USDT) or Lightning Address (sats), in the form on the right.
  2. Change something in the repositoryUse Edit on GitHub on a bounty: GitHub creates a branch in your fork and a commit.
  3. Open a pull request that closes the issuePut the bounty's Closes #N in the description (or add Payout: <address> to override your registered one). The bounty below shows your pull request as soon as GitHub tells us.
  4. Merge itThe merge webhook triggers the payout; follow it here and in your wallet.
