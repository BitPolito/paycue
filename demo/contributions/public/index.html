How it works

  1. A maintainer labels an issue bounty: 60000 (sats).
  2. You open a pull request with Closes #12.
  3. On merge, Payhook pays you: a Liquid address receives L-USDT through KaleidoSwap, a Lightning Address receives sats.
  4. Optional: put Payout: <address> in the PR description.
